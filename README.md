# 👗 Butik Łucji

Pierwsza gra Łucji (9 lat). Projektujesz ubrania, sprzedajesz je klientkom i otwierasz sklepy we Wrocławiu. Bez przegranej, do relaksu.

## Jak grać
Online: https://mmhouse61-svg.github.io/butik-lucji/ (aplikacja PWA: na iPadzie Udostępnij → Dodaj do ekranu początkowego). Lokalnie: otwórz `index.html`. Postęp zapisuje się sam.
